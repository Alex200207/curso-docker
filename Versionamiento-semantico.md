/**
 * Versionamiento dinámico (ejemplo: 1.1.1 o 1.0.0)
 *
 * El versionamiento dinámico utiliza una estructura de tres números separados por puntos (X.Y.Z):
 * - El primer número (X) representa la versión mayor. Se incrementa cuando hay cambios significativos o incompatibles.
 * - El segundo número (Y) es la versión menor. Se incrementa cuando se agregan funcionalidades compatibles.
 * - El tercer número (Z) indica la versión de parche. Se incrementa cuando se corrigen errores o se hacen mejoras menores.
 *
 * Ejemplo:
 * - 1.0.0: Primera versión estable.
 * - 1.1.1: Versión mayor 1, con una actualización menor (1) y un parche (1).
 *
 * Este sistema permite identificar fácilmente el tipo de cambio realizado en el software.
 */
