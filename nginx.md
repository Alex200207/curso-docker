# ¿Qué es Nginx?

Nginx es un servidor web de alto rendimiento que también puede funcionar como proxy inverso, balanceador de carga y servidor de aplicaciones. Es conocido por su eficiencia, estabilidad y capacidad para manejar múltiples conexiones simultáneas, lo que lo hace ideal para sitios web de alto tráfico.

https://hub.docker.com/_/nginx

Lo usaremos como un hosting 

$ docker run --name some-nginx -d -p 8080:80 some-content-nginx
